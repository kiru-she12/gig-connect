# GigConnect — Student Gig Marketplace

A complete, fully functional multi-page web application prototype built for **Uva Wellassa University (UWU)**.

## 🚀 Getting Started

To run the application locally, follow these steps:

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start Development Server**
   ```bash
   npm run dev
   ```

3. **Open in Browser**
   Navigate to the local URL (usually `http://localhost:5173`)

## ✨ Features

- **Public Landing Page**: Browse jobs without logging in.
- **Role-Based Access**: 4 distinct dashboards for Admin, Students, Clients, and Delivery Staff.
- **Smart Matching**: Student recommendations based on skill overlap.
- **Multi-step Posting**: Clients can post jobs with simulated 5% commission payment.
- **Admin Control**: Job approvals, user monitoring, and analytics charts.
- **Notifications**: Real-time (simulated) bell notification system.
- **Responsive Design**: Optimized for mobile and desktop viewing.

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS
- **Routing**: React Router v6
- **Charts**: Recharts
- **Icons**: Lucide React
- **Animations**: CSS Keyframes & Framer Motion
- **State**: Context API (In-memory)
